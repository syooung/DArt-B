## 1. 스토어드 프로시저 사용 방법 

<!-- 스토어드 프로시저에 관해 배우게 된 점을 적어주세요. -->
### 📌 개념
> SQL에 **프로그래밍 기능**을 더한 것. 자주 쓰는 쿼리를 묶어 저장해 두고 `CALL`로 호출한다.

### 📝 기본 형식
```sql
DELIMITER $$
CREATE PROCEDURE 프로시저_이름(IN 또는 OUT 매개변수)
BEGIN
    -- SQL 코드
END $$
DELIMITER ;

CALL 프로시저_이름();
```
- `DELIMITER`는 프로시저 안의 SQL 끝(`;`)과 프로시저 끝(`$$`)을 구분하기 위해 쓴다.
- `CREATE` = ☕ 커피 자판기 만들기 / `CALL` = 커피 뽑기

### 🔑 매개변수
| 구분 | 키워드 | 비유 | 사용 |
| --- | --- | --- | --- |
| 입력 매개변수 | `IN` | 자판기에 넣는 동전 | `CALL proc(값)` |
| 출력 매개변수 | `OUT` | 커피가 담겨 오는 빈 컵 | `CALL proc(@변수)` → `SELECT @변수` |

### 💡 알게 된 점
- 프로시저를 **만들 때**는 테이블이 없어도 되지만, **CALL할 때**는 반드시 있어야 한다.
- `IF ~ ELSE`, `WHILE`, **동적 SQL**(`PREPARE` → `EXECUTE`)까지 쓸 수 있다.

## 2. 스토어드 함수와 커서 

<!-- 스토어드 함수와 커서에 관해 배우게 된 점을 적어주세요. -->

### 📌 스토어드 함수
> 내장 함수로 부족할 때 **직접 만드는 함수**. `RETURNS`로 형식을 정하고 `RETURN`으로 값 **하나**를 반환한다.

| | 스토어드 프로시저 | 스토어드 함수 |
| --- | --- | --- |
| 호출 | `CALL` | `SELECT` 문 안에서 |
| 매개변수 | `IN`, `OUT` | 입력만 (IN 생략) |
| 반환 | 없음 (OUT으로 받음) | `RETURN` 값 1개 |

> ⚠️ 함수를 만들기 전에 `SET GLOBAL log_bin_trust_function_creators = 1;`을 한 번 실행해야 한다.

### 📌 커서
> 테이블의 행을 **한 행씩** 처리하는 방식. 주로 프로시저 안에서 쓴다.

**작동 순서**
1. 커서 선언 (`DECLARE CURSOR`)
2. 반복 조건 선언 (`CONTINUE HANDLER FOR NOT FOUND`)
3. 커서 열기 (`OPEN`)
4. 데이터 가져오기 (`FETCH`) + 처리 🔁 반복
5. 커서 닫기 (`CLOSE`)

### 💡 알게 된 점
- 행이 끝나면 `endOfRow`가 TRUE가 되고, `LEAVE`로 반복을 빠져나온다.
- 커서로 구한 평균 인원 수 **6.6**은 `AVG()`와 같다. 실무에선 AVG가 편하지만 행 단위 처리 흐름을 익힐 수 있었다.

## 3. 자동 실행되는 트리거 

<!-- 트리거에 관해 배우게 된 점을 적어주세요. -->
### 📌 개념
> 테이블에 `INSERT` · `UPDATE` · `DELETE`가 일어나면 **자동으로 실행**되는 코드. 테이블에 미리 부착해 둔다. 🔫

- `CALL`로 직접 실행할 수 없고, 매개변수도 쓸 수 없다.
- 백업을 깜빡하는 실수를 막아 **데이터 무결성**을 지킨다.

### 📝 기본 형식
```sql
CREATE TRIGGER 트리거_이름
    AFTER DELETE      -- 이벤트 발생 후 작동
    ON 테이블_이름
    FOR EACH ROW
BEGIN
    -- 실행할 코드
END
```

### 🗂️ OLD / NEW 테이블
| 이벤트 | NEW 테이블 | OLD 테이블 |
| --- | --- | --- |
| INSERT | 새 값 | - |
| DELETE | - | 예전 값 |
| UPDATE | 새 값 | 예전 값 |

### 💡 알게 된 점
- `OLD.열이름`으로 변경 전 데이터를 백업 테이블에 자동 저장할 수 있다. (수정 1건 + 삭제 4건 기록 확인)
- ⚠️ `TRUNCATE TABLE`은 DELETE 문이 아니라서 **트리거가 작동하지 않는다.**
