# 1️⃣ 🧠 핵심 개념 정리

이번 주 강의에서 가장 중요하다고 생각한 개념 3개를 골라 정리해주세요. 필요하다고 생각하면 3개보다 더 많이 정리해도 좋습니다.

> 예시 개념: 트리맵, 하이라이트 테이블, 도넛차트, 이중축, 결합축, 분산형 차트, 히스토그램, 필터, 그룹

| 핵심 개념 | 한 줄 설명 | 사용하는 상황 | 헷갈린 점 또는 주의할 점 |
| --- | --- | --- | --- |
| 예: 그룹 | 여러 멤버를 사용자가 직접 묶어 새 범주처럼 쓰는 기능 | 브랜드명이나 지역을 분석 목적에 맞게 묶을 때 | 필터와 달리 데이터를 제외하는 기능은 아님 |
| **트리맵** | 데이터를 중첩된 사각형으로 표시하며 색상과 크기를 측정값으로 표현함 | 직관적으로 데이터의 크기를 비교할 때 | 나타내야 하는 데이터의 수를 잘 조절해야함 |
| **하이라이트 테이블** | 색상이 입혀진 특수 테이블 | 범주형 데이터를 색상으로 비교할 수 있기 때문에 텍스트 테이블에 여러가지의 다양한 데이터를 나타내야 할 때 | 데이터 항목이 너무 많으면 직관적으로 알 수 없기 때문에, 필터를 활용해 상위 10개 등 필요한 정보만 추출하여 가독성을 확보하는 것이 중요함. 또한 너무 많은 색상을 사용하면 한눈에 파악하기 어렵기 때문에, 개수에 따라 적절한 색상 선택이 중요함. |
| **파이 차트** | 전체를 100%로 보았을 때 각 항목이 차지하는 비율을 부채꼴 모양의 조각으로 나타낸 차트 | 전체에 대한 비율을 표시할 때 | 축을 따로 가지고 있지 않기 때문에 임의의 축을 설정해주어야 함 |
| **도넛 차트** | 파이 차트의 중앙을 비워 도넛 형태로 만든 차트 | 전체 대비 비중을 보여줌과 동시에, 중앙 여백에 총합과 같은 수치를 보여줄 때 | 이중축을 사용할 때 두번째 축의 마크 크기를 첫번째 축보다 작게 조절해야함  |
| **이중축** | 서로 다른 두 개 측정값의 축을 고유하게 유지하며 한 시트에 겹쳐 보여주는 기능 | 단위나 범위가 전혀 다른 두 지표를 한번에 비교할 때 |  |
| **결합축** | 두 개 이상의 측정값을 단일 측정값 축으로 통합하여 동일한 공간에 보여주는 기능 | 단위가 같고 축 범위를 공유하는 여러 지표를 하나의 차트 안에서 비교할 때 |  |
| **분산형 차트** | 두 연속형 변수 간의 관계나 상관관계를 x축과 y축의 점 위치로 표현하는 차트 | 두 지표 간의 관련성이나 패턴을 찾을 때 | 측정값을 행,열에 놓으면 기본적으로 하나의 점으로만 뭉쳐 보여서, 세부 정보 마크에 차원을 추가해 데이터를 해체해줘야 함 |
| **히스토그램** | 연속형 수치 데이터를 구간차원으로 나누어 데이터의 분포와 빈도를 보여주는 차트 | 데이터가 어디에 집중되어 있는지 분포 상태를 확인할 때 | x축이 범주가 아닌 연속형 수치임 |
| **필터** | 조건에 맞는 데이터만 추출하여 시트에 보여주는 데이터 정화 기능 | 필요한 데이터만 선별하여 집중 분석할 때 | 필터를 여러 개 적용할 때 실행순서에 따라 결과가 달라지므로, 우선순위를 고려해 지정해야 함 |

# 3️⃣ 🚀 실습 확인문제

## 문제 1. 목적에 맞는 차트 선택하기 `[기본]` ✅

아래 분석 목적 중 **1개**를 선택하여 알맞은 차트를 만들어주세요.

1. 하위 범주별 매출 비중 확인
2. 매출과 수익의 관계 확인
3. 할인율 분포 확인
4. 지역과 제품 범주별 수익 상태 비교


▶️ **선택한 분석 목적:** 4. 지역과 제품 범주별 수익 상태 비교  
▶️ **선택한 차트:** 하이라이트 테이블  
▶️ **사용한 필드:** 지역, 범주, 합계(수익)   
▶️ **이 차트를 선택한 이유:** 지역별, 제품 범주별 수익 수치를 교차표 형태로 한눈에 파악할 수 있으며, 수익 금액에 따라 색상 명암이 다르게 적용되어 적자가 발생하는 항목과 높은 수익을 내는 항목을 직관적으로 빠르게 비교·분석할 수 있기 때문에 하이라이트 테이블을 선택함

## 문제 2. 제품명 그룹 만들기 `[응용]` 🔎

`제품 이름` 필드에서 아래 조건에 맞게 그룹을 만들어주세요. 그룹 필드 이름은 **Product Name Group**으로 설정합니다.

- `Samsung`으로 시작하는 제품: `Samsung group`
- `Apple`로 시작하는 제품: `Apple group`
- `Canon`으로 시작하는 제품: `Canon group`
- 나머지: `기타`

이후 그룹별 주문량을 막대그래프로 표현해주세요. 주문량은 `주문 Id`의 카운트로 계산합니다.


☑️ **그룹 생성 과정:** 데이터 창에서 '계산된 필드 만들기'를 선택하여 필드명을 'Product Name Group'으로 입력 ➡️ STARTSWITH 함수(또는 CONTAINS 함수)와 IF문 조건식을 활용해 제품 이름에 삼성, Apple, Canon이 포함된 제품을 각각 'Samsung group', 'Apple group', 'Canon group'으로 그룹화하고, 나머지는 '기타'로 분류하는 계산식을 작성함.   

☑️ **사용한 필드:** `Product Name Group`, `주문 Id (카운트 고유)`  

☑️ **그래프에서 확인한 인사이트:** '기타' 그룹이 압도적으로 많은 비중을 차지하는 가운데, 주요 3개 브랜드(애플 146건, 캐논 127건, 삼성 123건)의 주문량은 전반적으로 비슷한 수준을 보임. 굳이 비교하자면 Apple group의 주문량이 가장 많았고 Canon group, Samsung group 순으로 미세하게 집계되었습니다.

# 4️⃣ 📝 이번 주 회고

## 이번 주에 가장 유용하다고 느낀 차트

```
✅ 도넛 차트
파이 차트처럼 항목별 비율을 한눈에 파악할 수 있으면서도, 중앙의 빈 공간에 총 주문량이나 대표 수치를 추가로 강조할 수 있어서
시각적 완성도가 높다고 느꼈습니다.
특히 태블로 기본 메뉴에 없지만 이중 축을 만들어 크기와
색상을 조절해 직접 구현해보는 과정을 통해 태블로 축 활용과
마크 카드의 동작 방식을 깊이 이해할 수 있어 더욱 유용했습니다.

```

## 차트를 고를 때 앞으로 고려하고 싶은 기준

```
1. 분석 목적과 전달 메시지의 명확성
전체 대비 비중을 볼 때는 파이/도넛 차트, 두 수치 간 상관관계를 볼 때는 분산형 차트, 수치 간 직관적인 교차 비교에는 하이라이트 테이블을
선택하듯, 보여주고자 하는 데이터의 핵심 목적에 가장 적합한 차트 타입을 최우선으로 고려할 것 같습니다.

2. 시각적 가독성과 데이터 최적화
데이터의 모든 항목과 너무 많은 색상을 한 번에 담으려 하면 오히려 시각적 피로도가 높아진다는 점을 배웠습니다. 앞으로는 Top N 필터를
활용해 핵심 상위 데이터에 집중하고, 단일 명암이나 2가지 다중 색상 
팔레트처럼 색상을 단순화하여 시각적 직관성을 극대화하고 싶습니다.
```
