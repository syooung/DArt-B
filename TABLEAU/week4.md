# 1️⃣ 🧠 핵심 개념 카드

이번 주부터는 개념을 표로만 정리하지 않고, **개념 카드** 형태로 정리합니다. 계산 관련 개념은 “언제 쓰는지”와 “주의할 점”을 함께 적어야 나중에 다시 보기 좋습니다. 필요하다고 생각하면 2개보다 더 많이 정리해도 좋습니다.

> 예시 개념: 계층, 집합, 결합집합, 계산된 필드, 행 수준 계산, 집계 계산, 테이블 계산, 퀵테이블 계산

## 📌개념 1. `계층`

**1. 이 개념을 한 문장으로 설명하면?**

```
뷰에서 데이터를 드릴 다운해 값을 세부적으로 찾을 때 유용한 방법
```

**2. 언제 사용하나요?**

```
날짜별로 매출을 보고자 할 때, 분기별/월별/일별로 볼 수 있음
```

**3. 이번 실습에서 어떻게 확인했나요?**

```
우선 두 개의 필드를 선택한 뒤 우클릭하여 '위치' 계층을 만들어주고, 나머지 필드들을 '위치' 계층으로 드래그하였음.   
그 뒤로 지역>국가/지역>시/도>도시 순으로 순서를 정렬하여 (+) 기호를 클릭할수록 더 세부적인 값을 볼 수 있게 함.
```

**4. 헷갈린 점 또는 주의할 점은?**

```
계층을 만들고 난 뒤 순서 정렬이 중요할 거 같음 (예를 들어 큰거에서 작은거로 가게끔)
```

## 📌개념 2. `집합`

**1. 이 개념을 한 문장으로 설명하면?**

```
사용자가 직접 어떤 조건을 설정하고 그 조건을 기반으로 데이터들을 구분하는 방법
```

**2. 언제 사용하나요?**

```
예시: 수악을 많이 낸 상위 10기의 도시들을 표현하고자 할 때
```

**3. 이번 실습에서 어떻게 확인했나요?**

```
조건으로 묶어주고 싶은 필드(시/도)에서 우클릭하여 만들기 - 집합 만들기 - 상위 (수익) 을 하였음.  
그 다음 새로 생성된 '수익 기준 상위 도시'를 마크카드의 색상으로 드래그앤드롭 하니 10개의 도시에 색깔이 다르게 입혀짐.
```

**4. 헷갈린 점 또는 주의할 점은?**

```
집합을 만들 때 일반, 조건, 상위 이렇게 3가지로 나뉘는데 사용할 목적에 따라 어떤 것을 선택하는지가 중요할 것 같음.
```
## 📌개념 3. `결합된 집합`

**1. 이 개념을 한 문장으로 설명하면?**

```
두 가지의 조건을 적용하여 집합을 만들고 싶을 때 사용함
```

**2. 언제 사용하나요?**

```
예를 들어, 매출이 5만원 이상이고 수익률이 10% 이상인 도시의 데이터를 구분해보고 싶다면, 두개의 집합을 만들어야함
```

**3. 이번 실습에서 어떻게 확인했나요?**

```
필드를 두가지 만들고 (매출 5만원 이상, 수익률 10% 이상) 우클릭하여 결합된 집합 만들기를 통해 두가지 조건을 모두 충족시키는 옵션을 선택하였음. 
```

**4. 헷갈린 점 또는 주의할 점은?**

```
어떤 필드를 행에 두고, 어떤 필드를 마크 카드의 텍스트에 놓을지, 색상에 놓을지 드롭 하는게 헷갈렸음
```
## 📌개념 4. `계산된 필드`

**1. 이 개념을 한 문장으로 설명하면?**

```
데이터 원본에 있는 필드를 활용하여 새로운 필드를 만드는 기능
```

**2. 언제 사용하나요?**

```
기존 데이터 이외에 계산해야 할 데이터가 추가로 필요할 경우에 사용
1) 데이터 패널을 통해 생성하는 방법
2) 분석 탭을 활용해 생성하는 방법
3) 사용하고자 하는 필드 위에 마우스 우클릭
```

**3. 이번 실습에서 어떻게 확인했나요?**

```
데이터 패널에서 함수식을 이용한 새로운 필드(수익률)를 생성함.
```

**4. 헷갈린 점 또는 주의할 점은?**

```
데이터를 백분율로 표현하고 싶다면, 필드에서 우클릭한 후 숫자형식을 백분율로 바꿔주기!
```

# 3️⃣ 🚀 실습 확인문제

## 문제 1. 매출 상위지만 수익률이 낮은 지역 찾기 `[응용]` 🔎

매출이 상위 10곳에 속하지만, 수익률이 마이너스인 `시/도`를 확인해보세요.

> 수익률은 `SUM([수익]) / SUM([매출])`로 정의합니다.

아래 내용을 포함해주세요.

1. 만든 계산된 필드 이름과 수식
2. 만든 집합 조건
3. 최종 결과 캡처


**🔎 계산식**
- 필드 이름: `수익률(%)`
- 수식: `SUM([수익]) / SUM([매출])`

**🔎 집합 조건**
- **조건 1 (매출 상위 10)**: 시/도 필드를 기준으로 합계(매출)가 상위 10인 집합
- **조건 2 (수익률 마이너스)**: 시/도 필드를 기준으로 조건 수식을 `[수익률(%)] < 0`으로 설정한 집합  

**=>** 위 두 집합을 생성한 뒤, 교집합을 적용하여 매출이 상위 10곳이면서 수익률이 마이너스인 최종 조건 결합

**🔎 결과 해석** :  전체 시/도 중 매출 상위 10개 지역 내에서 수익률이 마이너스를 기록한 곳은 **Metro Manila**가 유일함. 표에 나타난 Metro Manila의 합계 매출은 149,247이며, 수익률은 -8.47%임.

## 문제 2. 배송까지 걸린 일수 계산하기 `[기본]` ✅

`주문 날짜`부터 `배송 날짜`까지 걸린 일수를 계산하는 필드를 만들어주세요. 필드 이름은 **배송까지 걸린 일수**로 설정합니다.

힌트: `DATEDIFF` 함수를 사용합니다.


**🔎 계산식**: `DATEDIFF('day', [주문 날짜], [배송 날짜])`

**🔎 계산 결과를 확인한 방법**: 주문 날짜와 배송 날짜를 '정확한 날짜/불연속형'으로 뷰에 올리고, 계산된 필드를 '차원'으로 변경하여 실제 일수와 직접 비교함.

**🔎 캡처 이미지**:

![alt text](<images/태블로 4주차 실습인증2.png>)

### 추가로, 같은 `주문 Id` 안에 여러 행이 있을 때 계산 결과를 해석할 때 주의할 점을 적어주세요.

```
주의할 점: 기본 집계(합계) 적용 시 한 주문 내 여러 제품(행)의 값이 중복 합산되어 일수가 부풀려지므로, 뷰에 올릴 때 필드를 '차원'으로 변경하거나 집계 기준을 '평균/최대값'으로 바꿔야 함.
```

# 4️⃣ 📝 이번 주 회고

## 계산을 사용할 때 가장 어려웠던 점

```
단순히 DATEDIFF 함수로 수식을 작성하는 것 자체는 어렵지 않았지만, 하나의 주문 안에 여러 행이 있을 때 태블로가 기본적으로 값을 합계(SUM)로 집계하여 배송 일수가 비정상적으로 부풀려지는 현상을 파악하는 것이 가장 헷갈렸습니다.
수식을 맞게 썼음에도 결과가 왜곡되는 이유를 찾고, 이를 해결하기 위해 측정값을 '차원'으로 변경하거나 집계 방식을 수정해야 한다는 태블로 특유의 작동 원리를 이해하는 과정이 까다로웠습니다.
```

## 다음에 더 연습하고 싶은 계산

```
오늘 배운 내용 중 가장 까다로웠던 '테이블 계산'과 '퀵테이블 계산'(36~38강)을 더 깊이 있게 연습해 보고 싶습니다.
행 수준 계산이나 일반 집계 계산과 달리, 테이블 계산은 화면에 데이터를 어떻게 배치하느냐에 따라 계산 방향과 결과가 완전히 달라져서 작동 원리를 직관적으로 파악하기가 어려웠습니다.
누적 합계, 차이, 비율 등을 구할 때 계산 기준과 패널을 자유자재로 다룰 수 있도록 다양한 데이터로 집중적인 복습을 해보고 싶습니다.
```
