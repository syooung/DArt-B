# 1️⃣ 🧠 핵심 개념 정리

이번 주 강의에서 가장 중요하다고 생각한 개념 3개를 골라 정리해주세요.  
단순히 강의 내용을 받아쓰기보다는, **내가 언제 이 개념을 쓸 수 있는지**까지 적어보는 것이 목표입니다.
필요하다고 생각하면 3개보다 더 많이 정리해도 좋습니다.

> 예시 개념: 데이터 해석기, 데이터 유형, 관계, 조인, 혼합, 유니온, 라이브, 추출

| 핵심 개념 | 한 줄 설명 | 사용하는 상황 | 헷갈린 점 또는 주의할 점 |
| --- | --- | --- | --- |
| 예: 관계 | 여러 테이블을 논리적으로 연결하는 방식 | 원본 테이블의 세부 수준을 유지하며 분석하고 싶을 때 | 조인과 결과가 어떻게 다른지 헷갈릴 수 있음 |
| **조인** | 공통된 열을 기준으로 여러 테이블을 가로로 결합하는 것 | 서로 다른 정보를 하나로 합칠때 (ex.고객테이블+주문테이블) | 행이 늘어날 수 있음 |
| **유니온** | 같은 구조의 데이터를 세로로 이어 붙이는 것 | 같은 형식의 데이터를 합칠때 (ex.2024년 데이터+2025년 데이터) | 열 이름과 데이터 구조가 비슷해야함. 조인과 달리 공통 키가 필요하지 않음 |
| **라이브** | 데이터를 원본 데이터 베이스에서 실시간으로 가져와 사용하는 방식 | 데이터가 자주 업데이트 되고 최신 데이터를 바로 확인해야 할 때 | 원본 데이터베이스에 계속 연결해야하므로 속도가 느려질 수 있음 |
| **추출** | 원본 데이터를 태블로 전용 추출파일로 저장해서 사용하는 방식 | 데이터가 크거나 복잡한 계산을 빠르게 처리하고 싶을 때 | 원본 데이터가 바뀌어도 추출 데이터를 새로 고침해야 반영됨 |

## 문제 2. 라이브와 추출 연결 비교하기 `[기본]` ✅

Tableau에서는 데이터를 연결할 때 라이브 연결과 추출 연결을 사용할 수 있습니다. 아래 두 상황에서 어떤 연결 방식이 더 적절한지 고르고, 이유를 설명해주세요.

### 상황 1

실시간으로 바뀌는 주식 시세 데이터를 확인하며 빠르게 의사결정을 해야 합니다.

```
선택한 연결 방식: 라이브
이유: 주식 시세가 실시간으로 변하므로 원본 데이터와 연결된 상태에서 최신 데이터를 바로 확인하고 빠르게 의사결정해야 하기 때문입니다.
```

### 상황 2

인터넷 연결이 불안정한 환경에서, 미리 다운로드한 여행 예산 데이터를 오프라인으로 확인하고 싶습니다.

```
선택한 연결 방식: 추출
이유: 인터넷 연결이 불안정하더라도 미리 데이터를 태블로의 추출 파일로 저장해두면 오프라인에서도 데이터를 확인할 수 있기 때문입니다.
```
