# 1️⃣ 🧠 선택 개념 카드

이번 주는 학술제 기간을 고려하여 개념 카드 작성도 가볍게 진행합니다. 아래 중 **1개만** 골라 정리해주세요. 필요하다고 생각하면 더 정리해도 좋습니다.

> 예시 개념: 스토리, 대시보드 탐색, 버튼, 드릴다운, 집합값 변경, 필터 동작, 하이라이트 동작

## 선택 개념. `필터 동작`

**1. 이 개념을 한 문장으로 설명하면?**

```
대시보드의 한 시트에서 마크를 클릭하면, 그 값을 조건으로 다른 시트의 데이터가 걸러지도록 연결하는 기능이다.
```

**2. 내 최종 대시보드에 적용했거나 적용할 수 있는 부분은?**

```
'지역별 수익률' 막대를 클릭하면 '하위범주별 수익' 차트가 해당 지역 기준으로 바뀌도록 적용했다.
별도의 필터 카드 없이 클릭만으로 "어느 지역의 어떤 하위범주가 수익을 깎는지"를 바로 확인할 수 있다.
```

**3. 시간이 부족하다면 생략해도 되는 이유는?**

필터 동작이 없어도 각 시트를 따로 보면 같은 정보를 얻을 수 있다. 상호작용은 탐색을 빠르게 해 주는 장치이지 분석 결과 자체는 아니므로,
시간이 부족하면 기본 차트와 인사이트를 먼저 완성하고 동작은 나중에 추가해도 된다.

## 문제 1. 최종 대시보드 완성하기 `[기본]` ✅

6주차에 기획한 내용을 바탕으로 최종 대시보드를 완성해주세요.

단, 이번 주는 부담을 줄이기 위해 아래 기준만 충족하면 됩니다.

1. 워크시트 2개 이상
2. 대시보드 제목 포함
3. 필터, 하이라이트, 매개변수, 드릴다운, 버튼 중 1개 이상 사용
4. 핵심 인사이트 작성


```
대시보드 제목: 매출이 크다고 수익이 좋은 건 아니다 — 지역·하위범주별 수익성 분석
사용한 데이터: DArt-B_sample_superstore.xls ('주문' 시트, Tableau Superstore 기반)
분석 질문: 매출 대비 수익률이 낮은 지역은 어디이며, 그 지역에서 수익을 떨어뜨리는 하위범주는 무엇인가?
사용한 Tableau 기능: 계산된 필드(수익률 = SUM(수익)/SUM(매출)), 발산형 색상, 도구 설명(평균 할인율), 대시보드 구성
선택 기능을 적용했다면: 필터 동작 — '지역별 수익률' 막대를 클릭하면 '하위범주별 수익' 차트가 해당 지역 기준으로 바뀌어, 지역별 적자 품목을 클릭 한 번으로 확인할 수 있음
핵심 인사이트 1: 동남아시아의 수익률은 2.02%로, 약 20%인 북아시아의 10분의 1 수준에 그쳐 4개 지역 중 수익성이 가장 낮다.
핵심 인사이트 2: 동남아시아에서는 테이블(약 -18.6K)과 액세서리(약 -8.6K)의 적자가 특히 크고, 테이블의 평균 할인율은 48%로 높아 과도한 할인이 지역 수익률을 끌어내리는 주요 원인으로 보인다.
```

## 문제 2. 7주간 Tableau 회고 `[기본]` ✅

짧게 작성해도 괜찮습니다.

```
가장 많이 성장했다고 느낀 부분: 처음에는 차원과 측정값 구분부터 헷갈렸지만, 이제는 분석 질문을 먼저 정하고 그에 맞는 차트와 계산된 필드를 직접 구성할 수 있게 되었다. 6주차에 고민했던 할인율 표현을 별도 차트 대신 툴팁으로 넣어, 화면을 복잡하게 만들지 않고 정보를 더하는 방법을 익혔다.
아직 어렵게 느껴지는 부분: LOD 식(FIXED, INCLUDE, EXCLUDE)과 테이블 계산이 어떤 집계 수준에서 계산되는지 헷갈려서, 결과가 예상과 다를 때 원인을 찾는 데 시간이 걸린다.
앞으로 프로젝트에서 Tableau를 어떻게 활용해보고 싶은지: 학술제 같은 데이터 분석 프로젝트에서 EDA 결과를 대시보드로 정리하고, 필터 동작을 활용해 청중이 직접 눌러보며 결과를 이해할 수 있는 발표 자료로 활용하고 싶다.
```
