# 1️⃣ 🧠 핵심 개념 카드

이번 주에는 아래 개념 중 2개를 골라 개념 카드로 정리해주세요. 필요하다고 생각하면 2개보다 더 많이 정리해도 좋습니다.

> 예시 개념: 대시보드, 바둑판식/부동, 컨테이너, 레이아웃 패널, 필터 동작, 하이라이트 동작, URL 동작, 매개변수 변경 동작

## 개념 1. `하이라이트 동작`

**1. 이 개념을 한 문장으로 설명하면?**

```
한 시트에서 선택한 값과 관련된 마크를 다른 시트에서 강조하고, 나머지는 흐리게 표시하는 대시보드 동작이다.```
```
**2. 언제 사용하나요?**

```
전체 맥락은 유지한 채 특정 항목만 눈에 띄게 비교하고 싶을 때 사용한다.
데이터를 숨기는 필터 동작과 달리 다른 값도 화면에 그대로 남는다.
```

**3. 이번 실습에서 어떻게 확인했나요?**

```
'범주별 매출' 막대에서 특정 범주를 선택하면 '월별 매출 추이' 그래프에서 해당 범주의 선만 진하게 강조되고 나머지 범주는 흐려지는 것을 확인했다.
```

**4. 헷갈린 점 또는 주의할 점은?**

```
두 시트에 같은 필드(범주)가 있어야 하이라이트가 연결된다. 대상 하이라이트를 '모든 필드'로 두면 의도하지 않은 마크까지 강조될 수 있어서 '선택된 필드'로 지정하는 것이 안전하다.
```

## 개념 2. `바둑판식 / 부동`

**1. 이 개념을 한 문장으로 설명하면?**

```
바둑판식은 개체를 격자에 겹치지 않게 자동 정렬하는 배치 방식이고, 부동은 위치와 크기를 직접 정해 다른 개체 위에 띄워 놓는 배치 방식이다.
```

**2. 언제 사용하나요?**

```
대부분의 시트와 제목은 바둑판식으로 깔끔하게 정렬하고, 범례·필터 카드·로고처럼 특정 위치에 겹쳐 두고 싶은 요소에는 부동을 사용한다.
```

**3. 이번 실습에서 어떻게 확인했나요?**

```
두 시트와 제목은 바둑판식으로 배치해 화면이 자동으로 나뉘는 것을 확인했고, 범례를 부동으로 바꿔 그래프 위 빈 공간에 올려 공간을 절약했다.
```

**4. 헷갈린 점 또는 주의할 점은?**

```
부동 개체는 화면 크기가 바뀌면 다른 요소를 가리거나 위치가 틀어질 수 있다. 대시보드 크기를 '고정'으로 설정해 두는 것이 좋다.
```
