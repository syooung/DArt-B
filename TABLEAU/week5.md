# 1️⃣ 🧠 핵심 개념 카드

이번 주에는 아래 개념 중 2개를 골라 개념 카드로 정리해주세요. 필요하다고 생각하면 2개보다 더 많이 정리해도 좋습니다.

> 예시 개념: LOD, FIXED, INCLUDE, EXCLUDE, 매개변수, 마크카드, 서식계층

## 개념 1. `LOD (FIXED)`

**1. 이 개념을 한 문장으로 설명하면?**

```
LOD는 "Level of Detail"의 줄임말로, 뷰에 세부 수준을 나타냄.  
FIXED LOD는 현재뷰에 있는 차원과 상관없이 계산된 필드에서 원하는 차원을 따라 계산하는 표현식.
```

**2. 언제 사용하나요?**

```
계산할 수준을 세부적으로 제어 가능하도록 할 때 사용함
1) FIXED 에서 설정한 차원이 뷰에 포함되어 있을 때
2) FIXED 에서 설정한 차원이 뷰에 포함되어 있지 않을 때
와 같이 사용 방법이 두가지로 나뉨
```

**3. 이번 실습에서 어떻게 확인했나요?**

```
지역별 매출을 표시할 때, 계산된 필드 만들기에서   
{FIXED [지역] ; SUM([매출])} 입력.

```

**4. 헷갈린 점 또는 주의할 점은?**

```
- FIXED는 뷰의 차원과 무관하게 계산되고, INCLUDE/EXCLUDE는 뷰의 차원에 더하거나 빼는 방식이라 구분이 필요하다.
- FIXED는 일반 필터보다 먼저 계산되므로, 필터를 적용해도 값이 안 바뀔 수 있다. (필터를 '컨텍스트에 추가'해야 반영됨)
- 중괄호 { }와 콜론 : 위치를 헷갈리지 않도록 주의해야 한다.
```

## 개념 2. `매개변수`

**1. 이 개념을 한 문장으로 설명하면?**

```
사용자가 값을 직접 선택·입력할 수 있게 만든 변수로, 계산된 필드나 필터 등에 연결해 뷰를 동적으로 바꿀 수 있다.
```


**2. 언제 사용하나요?**

```
- 하나의 그래프에서 매출/수익/수량처럼 보고 싶은 지표를 바꿔 볼 때
- 기준값(임계값, 목표값 등)을 사용자가 조절하게 하고 싶을 때
- 필터로는 처리하기 어려운 "계산 방식 자체의 선택"이 필요할 때
```

**3. 이번 실습에서 어떻게 확인했나요?**

```
`지표 선택` 매개변수(매출, 수익, 수량)를 만들고, CASE 문으로 선택값에 따라 집계가 바뀌는 계산된 필드를 만들었다.
매개변수 컨트롤에서 값을 바꾸면 하위 범주별 막대그래프의 값이 즉시 바뀌는 것을 확인했다.
```

**4. 헷갈린 점 또는 주의할 점은?**

```
- 매개변수만 만들어서는 아무 변화가 없고, 반드시 계산된 필드와 연결해야 뷰에 반영된다.
- 매개변수는 데이터 소스의 필드가 아니라 독립된 값이다. 그래서 "매개변수 표시"를 켜야 컨트롤이 보인다.
- 값 목록의 데이터 유형(문자열/정수 등)과 CASE 문에서 비교하는 값의 형식이 일치해야 한다.
```

# 4️⃣ 📝 이번 주 회고

## LOD 또는 매개변수 중 더 어렵게 느껴진 것

```
LOD가 더 어려웠다. 집계 기준이 뷰의 차원과 별개로 움직인다는 점이 처음에는 직관적이지 않았고,
FIXED/INCLUDE/EXCLUDE의 차이를 구분하는 데 시간이 걸렸다. 반면 매개변수는 "선택값 → 계산된 필드 → 뷰"의
흐름이 단순해서 비교적 빨리 이해했다.
```

## 실제 분석에서 써보고 싶은 방식

```
지역(시군구)별 평균값을 FIXED로 고정해 개별 단위와 비교하는 방식을 써보고 싶다. 또 매개변수로
분석 지표를 바꿔 보는 대시보드를 만들면, 하나의 화면에서 여러 지표를 탐색할 수 있어 유용할 것 같다.
```
