# 3️⃣ 🚀 실습 확인문제

## 문제 1. 평균 배송일자와 비교하기 `[응용]` 🔎

상품들의 배송 소요일이 평균보다 빠른지 확인해보세요.

조건:

1. `국가/지역`과 `범주`별 평균 배송 소요일을 계산합니다.
2. 각 상품의 배송 소요일이 평균보다 빠르면 `빠름`, 같거나 느리면 `평균 이상`으로 표시합니다.

```
사용한 계산식:
LOD를 사용했다면 계산 기준:
결과 해석:
캡처 이미지:
```

---

## 문제 2. 매개변수로 지표 바꾸기 `[기본]` ✅

매개변수를 사용해 하나의 그래프에서 `매출`, `수익`, `수량` 중 하나를 선택해 볼 수 있도록 만들어주세요.

조건:

1. 지표 선택 매개변수를 만듭니다.
2. 선택한 지표에 따라 값이 바뀌는 계산된 필드를 만듭니다.
3. `하위 범주`별 선택 지표 값을 막대그래프로 표현합니다.

```
매개변수 이름:
계산된 필드 수식:
캡처 이미지:
```
