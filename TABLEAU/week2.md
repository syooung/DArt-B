# 1️⃣ 🧠 핵심 개념 정리

이번 주 강의에서 가장 중요하다고 생각한 개념 3개를 골라 정리해주세요. 필요하다고 생각하면 3개보다 더 많이 정리해도 좋습니다.

> 예시 개념: 차원, 측정값, 연속형, 불연속형, 막대그래프, 라인그래프, 맵, 레이블

| 핵심 개념 | 한 줄 설명 | 사용하는 상황 | 헷갈린 점 또는 주의할 점 |
| --- | --- | --- | --- |
| 예: 차원 | 데이터를 나누어 보는 기준이 되는 필드 | 범주별/지역별/날짜별로 값을 비교할 때 | 차원이 항상 불연속형인 것은 아님 |
| **측정값** | 수학적 계산이나 집계가 가능한 수치 데이터 필드 | 매출, 수량, 이익 등의 합계나 평균 값을 구할 때 | 측정값은 뷰에 올릴 때 기본적으로 집계(SUM 등)되어 표현됨 |
| **누적막대 그래프** | 하나의 막대를 세부 범주별로 쪼개어 전체 규모와 구성비를 함께 보여주는 그래프 | 전체 매출 등 합계와 그 안의 세부 항목별 비율을 동시에 비교할 때 | 하단 외에 중간에 위치한 조각들은 시작 기준선이 달라 정확한 크기 비교가 어려움 |
| **병렬막대 그래프** | 여러 개의 막대를 나란히 배치하여 항목 간 수치를 직접 비교하는 그래프 | 동일한 기준(예: 연도, 지역) 내에서 여러 범주의 값을 각각 대조할 때 | 비교하려는 범주의 개수가 너무 많아지면 화면이 좁아지고 가독성이 떨어짐 |
