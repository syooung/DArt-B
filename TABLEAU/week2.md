# 3️⃣ 🚀 실습 확인문제

## 문제 1. 기본 그래프 만들기 `[기본]` ✅

Superstore `주문` 데이터를 사용하여 아래 그래프 중 **2개**를 선택해 만들어주세요.

1. `범주`별 `매출` 막대그래프
2. `주문 날짜` 기준 월별 `매출` 라인그래프
3. `국가/지역` 또는 `시/도` 기준 매출 맵

각 그래프마다 아래 내용을 작성해주세요.

```
그래프 이름:
사용한 필드:
그래프에서 확인한 인사이트:
캡처 이미지:
```

---

## 문제 2. 누적막대 그래프로 매출 구성 보기 `[응용]` 🔎

`범주`와 `하위 범주`를 사용하여 매출 구성을 누적막대 그래프로 표현해주세요.

그래프에는 아래 내용이 드러나도록 만들어주세요.

- 범주별 전체 매출 규모
- 각 범주 안에서 하위 범주가 차지하는 매출

```
풀이 과정:
사용한 필드:
그래프에서 확인한 인사이트:
캡처 이미지:
```
